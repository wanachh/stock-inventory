# StockPulse

> ระบบจัดการสต็อกและคำนวณต้นทุนสินค้าจริงตามมาตรฐานบัญชี  (First-In, First-Out)

---

## 🎯 จุดประสงค์ของระบบ (Project Purpose)

**StockPulse** พัฒนาขึ้นเพื่อช่วยให้ธุรกิจและทีมงานสามารถจัดการสต็อกสินค้าและควบคุมต้นทุนได้อย่างแม่นยำ โดยบันทึกราคาซื้อจริงของสินค้าในแต่ละรอบ (Lot/Batch) และคำนวณต้นทุนการเบิกจ่ายตามหลักการ **เข้าก่อน-ออกก่อน (FIFO)** แทนการเฉลี่ยต้นทุน เพื่อให้ตัวเลขทางบัญชีและภาษีถูกต้องตรงตามจริง

---

## ✨ ฟีเจอร์หลัก (Key Features)

* 📦 **จัดการสต็อกและล็อตสินค้า (Inventory & Batches)**: บันทึกข้อมูล SKU, บาร์โค้ด, หมวดหมู่สินค้า และแยกเก็บตามล็อตที่รับเข้าพร้อมราคาต้นทุนจริง
* 💰 **คำนวณต้นทุน แม่นยำ (Real-Cost  Engine)**: ทราบมูลค่าสินค้าคงเหลือจริง (Ending Valuation) และต้นทุนสินค้าที่ตัดออกไปจริง (Cost of Goods Out)
* 📑 **สมุดรายวันเข้า-ออก (Stock Journal & Audit Trail)**: ตรวจสอบประวัติการทำรายการย้อนหลัง แก้ไขหรือคืนสต็อกเข้าล็อตเดิมได้ พร้อมส่งออกไฟล์ CSV
* 🔔 **ระบบแจ้งเตือนสินค้าใกล้หมด (Low Stock Alerts)**: แจ้งเตือนเมื่อสินค้าในคลังลดลงต่ำกว่าเกณฑ์ขั้นต่ำ
* 📱 **รองรับการใช้งานทุกอุปกรณ์ (Responsive & Mobile-First)**: ใช้งานได้ราบรื่นทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ
* 🔍 **รองรับเครื่องสแกนบาร์โค้ด (Barcode Scanner Ready)**: รองรับทั้งการพิมพ์ค้นหาด้วยมือและยิงด้วยหัวอ่านสแกนเนอร์อัตโนมัติ
* 🔒 **ระบบความปลอดภัยเฉพาะทีม (Team Protection)**: มีระบบ Passcode ล็อคหน้าจอเพื่อจำกัดสิทธิ์เฉพาะทีมงาน

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS, Lucide Icons
* **Backend**: ASP.NET Core Minimal API (.NET 10), Entity Framework Core
* **Database**: SQLite / PostgreSQL
